# json

`json` is `loads` and `dumps`. `loads` takes the `object_hook`, `object_pairs_hook`, `parse_float`, `parse_int` and `parse_constant` callables. `dumps` takes `indent`, `sort_keys`, `ensure_ascii`, `check_circular`, `allow_nan`, `skipkeys`, `default`, `separators` and `cls`.

```edge-python
from json import dumps, loads

data = loads('{"name":"ada","tags":["math","cs"]}')
print(data["name"])
print(dumps({"k": [1, 2, 3], "ok": True}))
```

```output
ada
{"k": [1, 2, 3], "ok": true}
```

`indent` and `sort_keys` shape the output.

```edge-python
from json import dumps

print(dumps({"b": 1, "a": [True, None]}, indent=2, sort_keys=True))
```

```output
{
  "a": [
    true,
    null
  ],
  "b": 1
}
```

Integers cross as 128-bit values, so a round trip keeps numbers past 64 bits, and a float that holds a whole number keeps its `.0` so it comes back a float.

```edge-python
from json import dumps, loads

big = 2 ** 100
print(loads(dumps(big)) == big)
print(dumps(3.0))
print(loads(dumps(3.0)))
```

```output
True
3.0
3.0
```

A parse failure raises `json.JSONDecodeError`, which is `ValueError` here, nesting past 1000 levels raises `RuntimeError`, and a value with no JSON form raises `TypeError` unless `default` turns it into one.

```edge-python
from json import dumps, loads

try:
    loads("{nope")
except ValueError as e:
    print("parse failed:", e)

def helper():
    pass

try:
    dumps({"fn": helper})
except TypeError as e:
    print("dump failed:", e)
```

```output
parse failed: Expecting property name enclosed in double quotes: line 1 column 2 (char 1)
dump failed: Object of type function is not JSON serializable
```
