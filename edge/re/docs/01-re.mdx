# re

`re` works like Python's. `match` anchors at the start, `search` looks anywhere and `fullmatch` takes the whole string, and each hands back a `Match` or `None`.

```edge-python
import re

m = re.search(r"(\d+)-(\d+)", "tel 12-34")
print(m)
print(m.group(), m[1], m[2])
print(m.groups(), m.span(), m.start(2))
print(re.match(r"\d+", "abc123"))
```

```output
<re.Match object; span=(4, 9), match='12-34'>
12-34 12 34
('12', '34') (4, 9) 7
None
```

Named groups answer by name too, and a group that took no part reads as `None`.

```edge-python
import re

m = re.match(r"(?P<user>\w+)@(?P<host>\w+)", "ana@mail")
print(m["user"], m.groupdict())
print(re.match(r"(a)|(b)", "b").groups())
```

```output
ana {'user': 'ana', 'host': 'mail'}
(None, 'b')
```

`findall` gives the text of every match, or its groups when the pattern has them, and `finditer` gives each `Match` with its position.

```edge-python
import re

print(re.findall(r"\d+", "a1 b22 c333"))
print(re.findall(r"(\w)=(\d)", "a=1 b=2"))
for m in re.finditer(r"\d+", "a1 b22"):
    print(m[0], m.start())
```

```output
['1', '22', '333']
[('a', '1'), ('b', '2')]
1 1
22 4
```

`sub` replaces with a template, where `\1` and `\g<name>` bring back a group, or with a function that gets each `Match`. `count` caps how many, `subn` also says how many it replaced, and `split` cuts at every match.

```edge-python
import re

print(re.sub(r"(\w+)@(\w+)", r"\2.\1", "user@host"))
print(re.sub(r"\d+", lambda m: str(int(m[0]) * 2), "a1 b22"))
print(re.subn(r"\d", "#", "a1b2c3", count=2))
print(re.split(r"[,;]\s*", "a, b;c"))
```

```output
host.user
a2 b44
('a#b#c3', 2)
['a', 'b', 'c']
```

`compile` checks a pattern once and hands back a `Pattern` with the same methods. The flags `re.I`, `re.M` and `re.S` ignore case, anchor at every line and let the dot match a newline, and `escape` makes any text match as written.

```edge-python
import re

p = re.compile(r"hola", re.I)
print(p, p.search("¡HOLA!"))
print(re.findall(r"^\w", "a\nb", re.M))
print(re.escape("1+1=2?"))
```

```output
re.compile('hola', re.IGNORECASE) <re.Match object; span=(1, 5), match='HOLA'>
['a', 'b']
1\+1=2\?
```

A bad pattern raises `re.error`, which is `ValueError` here, and a pattern that backtracks without end raises `RuntimeError` instead of hanging. Verbose patterns and `bytes` patterns are not supported.

```edge-python
import re

try:
    re.compile("(unbalanced")
except re.error as e:
    print("bad pattern:", e)

try:
    re.search("(a+)+$", "a" * 40 + "!")
except RuntimeError as e:
    print("too slow:", e)
```

```output
bad pattern: missing closing parenthesis at position 11
too slow: catastrophic backtracking: O(n^2) time or worse on this input, simplify nested quantifiers
```
